# WG4.3 method catalogue

Generated by `python tools/generate_method_docs.py`; edit [methods.json](docs/catalogue/methods.json), then regenerate. The JSON is the current source of truth. The CSV is a generated export.

## Status and scope

**Fully implemented** means essential components are present, integrated and covered by numerical tests **for the named repository scope**. Some names explicitly identify repository adaptations; this does not certify reproduction of the unrestricted original criterion. **Partially implemented** means code exists with known essential gaps (currently disabled). **Not implemented** means no usable corresponding implementation exists. **Requires review** means active code exists but source completeness cannot yet be established; it is not silently counted as complete or as a proven coding omission.

Validation is independent: `not_tested`, `basic_numerical_tests`, `reference_examples_reproduced`, `independently_validated`. No current entry claims published-dataset reproduction or independent experimental validation. CAIM’s independent calculation of supplied equations is numerical verification. An execution sweep is not scientific validation.

CA = constant amplitude; P/NP = proportional/non-proportional. Repeating arbitrary paths are within the research scope; current workbook import supports a single-frequency harmonic cycle. Life from a fitted damage curve is distinct from a published native life law. [Audit](docs/method-audit.md) records shear conventions, clipping, material-property approximations and `_ext` variants. `_ext` is a repository maximum-damage selection, not another counted theory.
