# G01: Papuga–Růžička critical-plane criterion (PCR; later PCRN)

**Prepared Issue body; not an open GitHub Issue.** Before posting, search open and closed Issues for the permanent ID and aliases. Do not create a duplicate. Suggested labels: `method:critical-plane`, `status:partial`, `help-wanted`, `validation-needed`. No `good-first-issue` claim is made.

## Scope and scientific reference

- Primary family: Critical plane; secondary: Stress critical plane.
- Status: Fully implemented; enabled: True.
- Authors/year: J PAPUGA, M RUZICKA (2008).
- Reference: Two new multiaxial criteria for high cycle fatigue computation, International Journal of Fatigue.
- DOI: https://doi.org/10.1016/j.ijfatigue.2007.02.015
- Reference evidence: Verified exact-title Crossref work record; saved metadata in docs/research/doi-records.json.
- Mathematical evidence: Checked against Papuga & Ruzicka (2008) Eqs. (16), (17) and Appendices A, B on the PDF (2026-10-17).
- Principle: Maximum over planes of sqrt(a_c C_a^2 + b_c (N_a + t_-1/f_0 N_m)) with kappa-branch coefficients (Eq. 17); C_a = minimum circumscribed circle radius..
- Loading scope: Single-frequency harmonic CA, proportional and phase-shifted NP..
