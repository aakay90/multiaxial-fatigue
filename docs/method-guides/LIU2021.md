# Liu et al. (2021) modified shear strain amplitude (`LIU2021`)

> **Registry name:** `LIU2021` (and `LIU2021_ext`) · **Catalogue entry:** [I_LIU2021](../../METHODS.md#i_liu2021) ·
> **Source:** Liu, Ran, Wei & Zhang (2021), <https://doi.org/10.1016/j.ijpvp.2021.104532> ·
> **Implementation:** [`cp_methods/liu2021.py`](../../src/multifat/models/cp_methods/liu2021.py)

## Overview

- **Type and family:** strain-based critical-plane criterion (TNP-family modified shear strain
  amplitude).
- **Idea:** modify the maximum engineering shear strain amplitude by a normal-stress and
  normal-strain interaction term scaled by $G$ and the shear fatigue strength coefficient
  $\tau_f'$, replacing the empirical fitting constant of earlier models with material constants.
- **Mean stress:** enters through the tensile peak normal stress $\sigma_{n,\max}$.
- **Proposed for:** multiaxial fatigue life prediction of metals under proportional and
  non-proportional loading.
- **Status:** implemented for the declared repository scope ("requires review" in the catalogue).
  The algebraic equivalence between Eqs. (19)/(23) and Eq. (27) and limiting cases are tested in
  `tests/methods/test_liu2021.py`; full-source verification of the unsubscripted $\Delta\varepsilon$
  term remains unresolved.

## Original formulation

Liu et al. (2021, Eq. 27, p. 7) define the modified shear strain amplitude on the maximum shear
strain plane:

```math
\frac{\gamma^*_{\max}}{2} = \frac{\Delta\gamma_{\max}}{2}
\left(1 + \frac{\sigma_{n,\max}\sqrt{\sigma_{n,\max}\,E\,\Delta\varepsilon}}{2\,G\,\Delta\gamma_{\max}\,\tau_f'}\right),
```

which combines Eq. (19) with the material sensitivity factor $k'$ from Eq. (23, p. 5) and
$G = E / [2(1 + \nu)]$ (Eq. 18). Life is obtained in the paper from a torsional strain–life curve.

## Repository implementation

Expanding the product removes the $1/\Delta\gamma_{\max}$ singularity at $\Delta\gamma_{\max} = 0$:

```math
\mathrm{DP} = \frac{\Delta\gamma}{2} + \frac{\sigma_{n,\max}\sqrt{\max(\sigma_{n,\max}\,E\,\Delta\varepsilon_n,\,0)}}{4\,G\,\tau_f'},
```

where $\Delta\gamma = 2\lVert(\Delta\varepsilon_{xz},\,\Delta\varepsilon_{yz})\rVert$ is the
engineering shear strain range on the candidate plane, $\Delta\varepsilon_n = \lvert\Delta\varepsilon_{zz}\rvert$
is the normal strain range on that plane, and $\sigma_{n,\max} = \max(\sigma_{zz,0},\,\sigma_{zz,1},\,0)$.
DP is dimensionless.

- `LIU2021`: DP on the plane maximising $\Delta\gamma$ (with ties resolved toward the larger DP).
- `LIU2021_ext`: largest DP over all candidate planes (repository variant).
- Out-of-phase loading: shear range uses the longest chord (`np_shear_rule = "longest_chord"`).

**Repository choices**

- *Normal strain range $\Delta\varepsilon$.* Eqs. (23) and (27) print an unsubscripted
  $\Delta\varepsilon$; the repository reads it as the normal strain range $\Delta\varepsilon_n$ on
  the candidate plane.
- *Algebraic expansion.* Expanding the outer $\Delta\gamma_{\max}/2$ keeps the limit finite when
  $\Delta\gamma = 0$.
- *Compression clipped.* $\sigma_{n,\max} < 0$ is clipped to $0$.
- *Shear coefficient $\tau_f'$.* Optional; when omitted from the workbook and `--constants`, it is
  estimated from `Su` via the Uniform Material Law ($\sigma_f' = 1.5\,S_u$) and von Mises
  ($\tau_f' = \sigma_f'/\sqrt{3}$, `ensure_shear_fatigue_props`) with a `RuntimeWarning`. Fitted
  Basquin constants from `multifat-pipeline` are not passed to `LIU2021` so this documented
  fallback is preserved.
- *Elastic strains and life curve.* Workbook strains are linear elastic; life uses the shared
  master curve $\mathrm{DP} = A N_f^b$
  ([README](README.md#from-damage-parameter-to-life-the-master-curve)).

| --- | --- | --- | --- | --- |

| $S_u$ | `Su` / Summary | MPa | workbook | yes (needed for fallback $\tau_f'$) |
| $\tau_f'$ | `tau_f` / Summary | MPa | workbook, `--constants`, or UML+Mises estimate | no ($> 0$) |
| $\boldsymbol\sigma(t)$ | `S_mean`, `S_sin`, `S_cos` | MPa | Dataset sheet | yes |

## Calibration

1. **Original procedure.** $\tau_f'$ is taken from the material's torsional fatigue properties
   (or $\sigma_f'/\sqrt{3}$ via Eq. 18), and $\gamma^*_{\max}/2$ is mapped through the torsional
   strain–life curve.
2. **Repository.** `LIU2021` has no fitted criterion constant. `tau_f` is read from the workbook or
   estimated from `Su`; the master-curve parameters $A$, $b$ are fitted on the uniaxial $R = -1$
   design tests.

## Worked example

Using the GH4169 elastic and fatigue constants from Table 2 (p. 7) of Liu et al. (2021):
$E = 182$ GPa, $\nu = 0.325$, $S_u = 1400$ MPa, $\tau_f' = 1565.2/\sqrt{3}$ MPa (demonstration with
linear-elastic strains, not experimental life validation).

```python
import math
import numpy as np

from multifat.models.registry import get_models
from multifat.planes.sampling import build_R_list

E, nu = 182000.0, 0.325  # MPa, - (Table 2)
G = E / (2.0 * (1.0 + nu))
Su = 1400.0
tau_f = 1565.2 / math.sqrt(3.0)  # MPa (Table 2)
planes = build_R_list(n1=20, n2=40)
zero = np.zeros((3, 3))
X = np.diag([1.0, 0.0, 0.0])  # unit uniaxial stress along x
T = np.zeros((3, 3))
T[0, 1] = T[1, 0] = 1.0  # unit shear stress tau_xy


def hooke(S):
    """Isotropic linear-elastic strain tensor (tensorial shear components)."""
    return ((1 + nu) * S - nu * np.trace(S) * np.eye(3)) / E


def evaluate(model, params, S_mean, S_sin, S_cos=zero):
    """Standard and _ext DP of S(t) = S_mean + S_sin sin(wt) + S_cos cos(wt), elastic strains."""
    result = model.evaluate_case(
        S0=S_mean + S_sin,
        S1=S_mean - S_sin,
        E0=hooke(S_mean + S_sin),
        E1=hooke(S_mean - S_sin),
        params=params,
        R_list=planes,
        harmonics={
            "S_mean": S_mean,
            "S_sin": S_sin,
            "S_cos": S_cos,
            "E_sin": hooke(S_sin),
            "E_cos": hooke(S_cos),
        },
    )
    return result.values[""], result.values["_ext"]


liu2021 = get_models(["LIU2021"])[0]
params = {"E": E, "nu": nu, "Su": Su, "tau_f": tau_f}

s_a, t_a = 400.0, 250.0
dp_tension, ext_tension = evaluate(liu2021, params, zero, s_a * X)
dp_torsion, _ = evaluate(liu2021, params, zero, t_a * T)

# Tension on 45 deg max-shear plane: d_gam = 2(1+nu)s_a/E, d_eps_n = (1-nu)s_a/E, sigma_n,max = s_a/2
d_gam_45 = 2.0 * (1.0 + nu) * s_a / E
d_eps_45 = (1.0 - nu) * s_a / E
sn_45 = s_a / 2.0
tension = 0.5 * d_gam_45 + sn_45 * math.sqrt(sn_45 * E * d_eps_45) / (4.0 * G * tau_f)
# Torsion on tau_xy plane: sigma_n,max = 0 -> DP = tau_a / G
torsion = t_a / G

assert abs(dp_tension - tension) < 1e-8 * tension
assert abs(dp_torsion - torsion) < 1e-8 * torsion

print(f"LIU2021 tension 400 MPa: {dp_tension:.6f} (LIU2021_ext {ext_tension:.6f})")
print(f"LIU2021 torsion 250 MPa: {dp_torsion:.6f}")
```

Output:

```text
LIU2021 tension 400 MPa: 0.003099 (LIU2021_ext 0.003144)
LIU2021 torsion 250 MPa: 0.003640
```

## Verification and limitations

- [`tests/methods/test_liu2021.py`](../../tests/methods/test_liu2021.py) verifies Eqs. (19)/(23)/(27)
  consistency, zero normal-stress and removable zero-shear limits, and the `tau_f` fallback warning.
- [`tests/test_method_audit.py`](../../tests/test_method_audit.py) checks the closed-form plane value.
- Paper inconsistencies noted in `test_liu2021.py` (Eqs. 3 and 6) are not used; the reading of
  unsubscripted $\Delta\varepsilon$ as the plane normal strain range remains a repository interpretation.
